## 4. 구현 상세

### 4.1 add 함수 (`add.ts`)

```typescript
export function add(a: number, b: number): number {
  return a + b;
}
```

- **타입:** `(a: number, b: number) => number`
- **동작:** JavaScript `+` 연산과 동일
- **부수 효과:** 없음

### 4.2 지원 범위

- 정수, 실수, 양수, 음수, 0

### 4.3 사용 예시

```typescript
add(2, 3);      // 5
add(-2, 3);     // 1
add(-2, -3);    // -5
add(1.5, 2.3);  // 3.8
add(-1.2, 0.5); // -0.7
```

### 보장되는 것

| 항목 | 설명 |

| 타입 계약 | `number` 2개 입력 → `number` 반환 |
