**Cursor Command란?**
- `.cursor/commands/*.md`에 저장한 재사용 프롬프트 템플릿
- 채팅창 `/` 입력 → 목록에서 선택

**Command 파일 예시:** `.cursor/commands/export-session.md`
- 번호 규칙: Report·Prompting 최대 번호 + 1
- 생성 파일: `Report/NN.REPORT.md`, `Prompting/NN.Export-Transcript.md`
- 보고서·Transcript 형식, 절차, 금지 사항 명시

**실행:** Agent 모드 → `/export-session` (+ 선택적 세션 주제)

**번호 규칙:** `01.REPORT.md`, `01.Export-Transcript.md` 패턴 (현재 01~04 존재)

`export-session.md` 수정:
- **추가 입력 없이 즉시 실행**
- 세션 주제·산출물·Transcript는 **현재 채팅**에서 자동 추출
- 사용자에게 **추가 질문 금지**

| 이전 | 지금 |
|------|------|
| `/export-session` + 주제 추가 | `/export-session` + Enter 만 |

**User**

export-session.md와 export.md의 차이점은 뭔가요?

---

**Cursor**

**차이는 거의 없습니다.** 둘 다 같은 작업을 하는 **별칭(alias)** 관계.

| 항목 | `export.md` | `export-session.md` |
|------|-------------|---------------------|
| 채팅 명령어 | `/export` | `/export-session` |
| 하는 일 | Report + Transcript 생성 | 동일 |

파일명 = Command 이름. 내용은 제목·첫 문장(어느 명령으로 호출됐는지)만 다르고 나머지 동일.

**권장:** 편한 쪽 하나만 사용. 짧게 `/export`, 의미 분명하게 `/export-session`.
