**동작**

1. **초기값** — `grid_g1` (빈칸은 `QSpinBox` special value로 빈 표시)
2. **[검증]** 클릭 시:
   - `InputHandler.validate(grid)` → E002/E003이면 입력 오류 표시
   - 통과 시 `validate_lines(grid)` → `status` + `failed_lines` 표시
3. **실패 줄** — `R2, C2, D1` 형식으로 표시

**`GridUI` (`grid_ui.py`)**
- 4×4 `QSpinBox`, 범위 0~16
- `setSpecialValueText("")` — 0일 때 빈 칸
- `set_grid(grid)` / `get_grid()` API

**`ResultDisplay` (`result_display.py`)**
- `show_input_error(error_code)` — E002/E003 메시지
- `show_validation(result)` — status별 색상 + `failed_lines` 목록

**`ValidationWindow` (`validation_app.py`)**
- G1 SSOT 초기 격자 로드
- `_on_validate`: `InputHandler.validate` → `validate_lines` 순서
- `main()` 진입점
