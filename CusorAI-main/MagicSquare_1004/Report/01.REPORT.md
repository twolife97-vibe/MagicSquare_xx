## 4. Mom Test 분석

### 4.1 표면 문제 (잘못된 정의 — 솔루션 혼입)

Mom Test에서 **문제 정의에 쓰면 안 되는** 문장들:

- “4×4 마방진을 **BCE로 분류**하고 `MagicSquare` / `Solver` / `GridUI` **프로그램부터 만든다**.”
- “빈칸 2개를 **Solver 알고리즘**으로 **자동 채우는 프로그램**을 먼저 만든다.”
- “**GridUI** / PyQt **UI 프로그램**을 설계하는 것이 문제다.”
- “**실패 조건 3개 도출** + BCE 설계만 하고 **테스트 없이** 끝낸다.”

→ **‘무엇을 만들지’** 만 있고, **불편·비용·과거 행동**이 없음.

### 4.2 진짜 문제 (한 문장)

> 4×4 부분 마방진에서 빈칸 2개를 채운 뒤 **행·열·대각선(10선) 합 34 여부를 확인할 때 일부 줄(예: 대각선)을 빼먹어 맞는지 판정하지 못하고**, 같은 시도를 반복하며 **20분** 같은 시간을 잃는다.
