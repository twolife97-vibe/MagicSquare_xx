## 2. 핵심 결정·산출물

### 2.1 Command 구조

| 파일 | Command | 역할 |
|------|---------|------|
| `.cursor/commands/export-session.md` | `/export-session` | 세션 Export 본 Command |
| `.cursor/commands/export.md` | `/export` | 동일 동작 **별칭** (짧은 입력) |

두 파일은 **기능 동일**. 차이는 채팅에서 입력하는 슬래시 명령어 이름뿐.

### 2.2 번호·파일 규칙

| 종류 | 패턴 | 예시 (다음 세션) |
|------|------|------------------|
| 보고서 | `Report/NN.REPORT.md` | `Report/05.REPORT.md` |
| Transcript | `Prompting/NN.Export-Transcript.md` | `Prompting/05.Export-Transcript.md` |

- `Report/`·`Prompting/` 기존 최대 번호 + 1 (현재 04 → **05**)
- 2자리 번호 (`01`, `02`, …)
- 기존 파일 덮어쓰기 금지

### 2.3 자동화 원칙 (추가 입력 없음)

Command 실행 시 Agent가 **현재 채팅**에서 자동 추출:

- 세션 주제
- 생성·수정 파일 목록
- User/Cursor 대화 전문 (Transcript)

사용자에게 주제·번호·형식 **추가 질문 금지**.

### 2.4 진행 타임라인

| 순서 | 사용자 요청 | 결과 |
|------|-------------|------|
| 1 | Report·Prompting Export Command 작성·실행법 안내 | 절차·템플릿 설명 |
| 2 | Command 파일 생성 요청 | `export-session.md` 생성 |
| 3 | 추가 입력 없이 `/명령`만으로 처리 | 자동 추출·질문 금지 규칙 반영 |
| 4 | 짧은 별칭 요청 | `export.md` (`/export`) 추가 |
| 5 | 두 Command 차이 질문 | 별칭 관계 설명 |
| 6 | `/export` 실행 | 본 보고서·Transcript 생성 |
