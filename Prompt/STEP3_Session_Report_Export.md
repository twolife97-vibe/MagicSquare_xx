```
Report 폴더와 Prompt 폴더에 보고서와 프롬프트 저장
```

## 기대 산출물

| 경로 | 용도 |

## Report 포함 섹션

1. 메타 정보 (프로젝트, 단계, 페르소나, 작성일, STEP 1 근거)
2. Mom Test 결과 (페르소나, 진짜 문제, 증거 3줄)
3. 주제 한 문장
4. R-G-I-O
5. 성공 기준 3개 (증거 연결)
6. 표면 문제 — 하지 않을 것
7. 8계층 (Rule, Command, Skill, Test Loop)
8. 멘토 코멘트
