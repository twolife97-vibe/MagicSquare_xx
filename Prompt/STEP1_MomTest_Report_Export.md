# MagicSquare_xx STEP 1 — 보고서 내보내기

인터뷰 종료·워크북 정리 후 `Report` 폴더에 보고서를 생성할 때 사용한다.

---

## 프롬프트

```
Report 폴더에 보고서를 내보내줘
```

---

## 기대 산출물

**경로:** `Report/STEP1_MomTest_Report.md`

**포함 섹션:**

1. 메타 정보 (프로젝트, 단계, 페르소나, 작성일)
2. 페르소나
3. 인터뷰 답변 (과거 사실 — 표 형식)
4. 표면 문제 (솔루션 섞인 문장 — 금지 목록)
5. 진짜 문제 (한 문장)
6. 인터뷰 Q&A 흐름 요약
7. 멘토 코멘트 + STEP 2 후보 실패 조건 (인터뷰 사실에서 파생, 미검증 표시)
8. 부록 — 과제 맥락 (4×4 격자, ECB 연습 목표)

---

## 확장 프롬프트 (선택)

```
Report 폴더에 Mom Test STEP 1 보고서를 markdown으로 저장해.
인터뷰에서 확인된 과거 사실만 포함하고, 솔루션 제안은 표면 문제(금지) 섹션에만 넣어.
ECB·후속 작업은 기억 없으면 미확인으로 표시해.
```
