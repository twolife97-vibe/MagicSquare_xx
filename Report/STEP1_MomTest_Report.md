## 1. 페르소나

4×4 **부분 마방진**을 손으로 또는 코드로 다루는 **학습자**.

- 과제 맥락: 4×4 격자, 빈칸 2개, 1~16 사용, 행·열·대각선 합 = **34**
- 첨부 자료: ECB(Entity-Control-Boundary) 개념 분석 슬라이드 (4.1 Magic Square 프로젝트)

---

## 2. 인터뷰 답변 (과거 사실)

인터뷰에서 확인된 **구체적·과거·측정 가능**한 사실만 기록한다.

| # | 사실 |
|---|------|
| 1 | 첨부와 같은 4×4 부분 마방진 작업을 수행했고, **총 약 20분** 소요 |
| 2 | 빈칸 2개에 숫자를 넣고 **행·열·대각선(좌하→우상)은 34**로 맞춤 |
| 3 | **반대 대각선(우하→좌상)은 처음에 계산·확인하지 않음** |
| 4 | 행·열·대각선 하나가 맞는 동안 **「다 맞췄다」고 확신** |
| 5 | 대각선 확인은 **습관적으로 마지막**에 수행 |
| 6 | 막혔을 때의 순서: **문제 조건 다시 읽기 → 행 합 다시 세기 → 대각선 합 다시 세기** |
| 7 | **마지막 검토**에서 대각선 칸만 짚어 보다 **교차하는 두 줄**이 보임 |
| 8 | 두 번째 대각선 합을 셌을 때 **34가 아니었음** |
| 9 | **빈칸 2개 숫자를 변경**한 뒤, 행·열·대각선을 다시 계산 |
| 10 | **「끝」**이라고 판단할 때 마지막 행동: **행·열·대각선 전부 다시 계산** |

### 미확인 구간

- 20분 풀이 직후 ECB 분류·실패 조건 도출 등 **후속 작업** — 인터뷰ee 기억 없음, 본 보고서에서 제외

## 4. 진짜 문제 (한 문장)

> **행·열과 대각선 하나만 맞춰도 「끝」이라고 느끼지만, 마방진이 요구하는 검증 항목(특히 두 번째 대각선)을 처음부터 빠짐없이 돌리지 못해, 틀린 답을 확신한 채 시간을 쓰고 나중에 교차 대각선을 짚을 때까지 원인을 찾지 못한다.**

## 5. 인터뷰 요약 (Q&A 흐름)

| 질문 요지 | 답변 요지 |
|-----------|-----------|
| 마지막으로 4×4 부분 마방진을 다룬 경험 | 첨부 과제와 같이 작업, 어려움이 있었음 |
| 가장 막혔던 순간 | 빈칸 2개·행·열·대각선 하나는 맞췄으나 **대각선 하나 누락**, **20분** 소요 |
| 20분 동안 확신 vs 이상함 | **다 맞췄다고 확신**, 마지막 대각선 확인에서 발견 |
| 20분 동안 한 행동 | (후속) 반대 대각선 합 계산·원인 추적 |
| 대각선을 마지막에 본 이유 | **습관** |
| 원인 찾을 때 순서 | 조건 재독 → 행 합 → 대각선 합 |
| 두 대각선 인지 시점 | **마지막 검토** 중 대각선 칸 짚어 보며 **교차 두 줄** 확인 |
| 두 번째 대각선 확인 직후 | 합 계산 → **34 아님** → 빈칸 2개 숫자 변경 |
| 총 소요 시간 | **약 20분** (처음부터 끝까지) |
| 「진짜 끝」 마지막 행동 | 행·열·대각선 **전부 다시 계산** |
| 풀이 후 ECB 등 후속 작업 | **기억 없음** → 인터뷰 종료 |

## 6. 멘토 코멘트 (Mom Test 관점)

- 이번 인터뷰에서 드러난 것은 **기능 요구**가 아니라 **검증 루틴이 완료되기 전에 「확신」이 먼저 선다**는 **과거 행동 패턴**이다.
- 핵심 트리거: **교차하는 두 대각선 중 하나만** 먼저 맞춘 상태에서의 **조기 종료감**.
- STEP 2로 넘어갈 때는 「무엇을 만들까?」보다 **「확신하기 직전, 손/눈으로 무엇을 반복했는가?」**를 **실패 조건** 문장으로 옮기는 것이 적절하다.

### STEP 2 후보 실패 조건 (인터뷰 사실에서 파생, 미검증)

1. 행·열·대각선(1개)만 34일 때 「완료」로 판단한다.
2. 검증 시 **대각선 2개를 구분하지 않고** 하나만 반복 확인한다.
3. 문제 조건을 재독해도 **체크 항목 목록**으로 전환하지 않고 같은 합 계산만 반복한다.

> 위 3항은 인터뷰ee 1명·1회 경험에서 도출한 가설이며, 추가 인터뷰 또는 관찰 전까지 확정 문제로 취급하지 않는다.
