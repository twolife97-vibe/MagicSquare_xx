## 1. 주제 한 문장 (Mom Test 기반, 솔루션 최소화)

> **4×4 부분 마방진을 풀 때, 행·열·대각선 하나만 맞춘 상태에서 「끝」이라고 느끼기 전에, 마방진이 요구하는 검증 항목(두 대각선 포함)을 빠짐없이 돌릴 수 있는지부터 확인한다.**

앱·Validator·TDD·ECB 등 구현 방식은 주제에 넣지 않는다.

## 2. R-G-I-O

| | 내용 |
|---|------|
| **Role** | 4×4 부분 마방진 과제를 푸는 **학습자** — 손 계산·코드 작성·제출 직전 **검증**까지 담당 |
| **Goal** | 「다 맞췄다」는 **조기 확신** 없이, 행 4·열 4·대각선 2를 **한 번에 빠짐없이** 확인한 뒤에만 완료로 판단 |
| **Input** | 4×4 격자(빈칸 2개, 1~16), 과제 조건(합=34), Mom Test에서 나온 **실패 패턴**(한 대각선만 확인·마지막에만 대각선·같은 합 계산 반복) |
| **Output** | 검증 항목별 **통과/미통과** 결과(어떤 행·열·대각선이 34가 아닌지), 「끝」 선언 전 **체크리스트 완료 여부** |

## 3. 성공 기준 3개 (Mom Test 증거와 연결)

| # | 성공 기준 | 연결 증거 |
|---|-----------|-----------|
| **S1** | 「완료」 판단 **전에** 행 4·열 4·대각선 2 **10항**을 명시적으로 한 번씩 확인한다 (한 대각선만 보고 끝내지 않음). | ① 반대 대각선 미확인 채 확신 / ③ 끝낼 때 **전부** 다시 계산 |
| **S2** | 대각선 검증 시 **좌하→우상·우하→좌상 두 줄을 구분**해 각각 합을 확인한다 (「대각선」 하나로 뭉개지 않음). | ① 한 대각선만 34 / ③ 마지막 검토에서 **교차 두 줄** 발견 |
| **S3** | 막혔을 때 조건 재독·행 합·대각선 합 **반복만** 하지 않고, **체크 항목 목록**(10항)으로 전환해 **아직 안 본 항목**부터 확인한다. | ② 습관적 마지막 대각선·같은 패턴 반복 |

## 5. 8계층 — 이번 세션에서 만드는 것만

| 계층 | 이번 세션 산출물 | Mom Test 연결 |
|------|------------------|---------------|
| **Rule** | 「완료」 선언 전 **검증 10항**(행4·열4·대각2) 체크를 **필수**로 두는 Cursor Rule (조기 확신·한 대각선만 확인 금지) | ①③ 조기 확신 / ③ 전부 재계산 |
| **Command** | `/verify-magic-square` 등 — 주어진 4×4 격자에 대해 **10항 검증**을 실행하고 미통과 항목을 **목록**으로 출력하는 커맨드 | ② 같은 패턴 반복 → **항목 목록**으로 전환 (S3) |
| **(Skill)** | *(선택)* 4×4 부분 마방진 **검증 체크리스트** 절차 Skill — 두 대각선 구분·「끝」 전 전항 확인 | ①② 대각선 습관·한 줄만 확인 |
| **Test Loop** | 행/열/대각(2)/합34에 대한 **실패 케이스** 루프 — 특히 **두 번째 대각선만 틀린** 격자로 S1·S2 검증 | ③ 두 번째 대각선 34 아님 → 수정 후 재검증 |

### 이번 세션에서 만들지 않음

Entity, Control, Boundary, UI, Solver, ECB 문서화 등 상위·하위 계층.

## 6. 멘토 코멘트

- STEP 3 주제는 STEP 1 **진짜 문제**(조기 확신·검증 누락)에서 파생했으며, 솔루션(앱·클래스·TDD)은 **표면 문제**로 격리했다.
- 8계층 중 Rule·Command·Test Loop는 **「끝」 선언 전 10항 검증**이라는 동일 Goal을 Cursor 워크플로우로 고정하는 수단이다.
- Skill은 선택이지만, 두 대각선 구분·체크리스트 전환(S2·S3)을 반복 절차로 묶을 때 유용하다.
